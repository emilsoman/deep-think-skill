# Concept Map

Source: https://untools.co/concept-map/
Group: Systems Thinking
Use it for: showing how the concepts of a problem relate to each other.

## Steps

1. Write a focus question: the question that the map must answer.
2. List 10 to 20 key concepts.
3. Put the concepts in order from the most general to the most specific.
4. Connect concepts with labelled links. Each link plus its two concepts must make a sentence (a proposition). Example: "trial users → need → quick value".
5. Add cross-links between different parts of the map. Cross-links often show new ideas.

## Result file

The focus question. The propositions as a list ("concept → link → concept"). The cross-links, and the new ideas they show.
