# First Principles

Source: https://untools.co/first-principles/
Group: Problem Solving
Use it for: removing assumptions and building a solution from basic truths.

## Steps

1. Write down the problem and the usual way people think about it.
2. List all the assumptions in the usual way.
3. Question each assumption: "Is this really true? How do we know? What if it is false?" Use "Why?" many times.
4. Keep only the basic truths: facts that you cannot break down more.
5. Build a new solution from the basic truths only.

## Result file

The assumptions, each marked true, false, or not known. The basic truths. The new solution built from them, and how it is different from the usual way.

## Your view in the chat

Question the assumptions of the other agents. When an idea uses "everybody does it this way", ask why.
