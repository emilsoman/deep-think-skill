# Abstraction Laddering

Source: https://untools.co/abstraction-laddering/
Group: Problem Solving
Use it for: finding the correct level of the problem statement.

## Steps

1. Write the problem as a question: "How might we ...?"
2. Go **up** the ladder: ask "Why?" Write a more abstract version of the problem. Do this 2 to 3 times.
3. Go **down** the ladder: ask "How?" Write a more concrete version. Do this 2 to 3 times.
4. Look at all the levels. Select the level that is not too abstract (no clear action) and not too concrete (only one solution).

## Result file

The ladder from the most abstract to the most concrete statement. Mark the original statement and the recommended statement. Give the reason.

## Your view in the chat

Tell the other agents if they solve the problem at the wrong level. Example: they optimize a detail when the real goal is one level up.
