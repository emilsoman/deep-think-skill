# Ishikawa Diagram

Source: https://untools.co/ishikawa-diagram/
Group: Problem Solving
Use it for: finding all the possible causes of a problem.

## Steps

1. Write the problem (the effect) at the head of the fish.
2. Select the categories of causes. Common categories: People, Methods, Machines (tools), Materials, Measurements, Environment. Change them to fit the problem.
3. For each category, list possible causes. For each cause, ask "Why does this happen?" to find sub-causes.
4. Mark the causes that have the most evidence and the causes that are easy to test.

## Result file

The diagram as a nested list (category → cause → sub-cause). Then the top 3 causes to investigate, with the test for each.

## Your view in the chat

Other agents can find one cause and stop. You show the full set of causes. Point out categories that nobody talks about.

## If it does not fit

If the problem is not "why does X happen?", apply it to the causes of the main risk or the main obstacle to the goal.
