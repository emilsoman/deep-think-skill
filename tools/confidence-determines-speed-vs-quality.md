# Confidence Determines Speed vs. Quality

Source: https://untools.co/confidence-determines-speed-vs-quality/
Group: Decision Making
Use it for: deciding if a solution needs speed or quality.

## Steps

1. How sure are we that the **problem is important**? Use data, not opinion.
2. How sure are we that the **solution is correct**?
3. Put the problem on the two axes:
   - Low confidence that the problem is important: **focus on speed**. Make a quick test.
   - High confidence in the problem and the solution: **focus on quality**. Build it well.
   - High confidence in the problem, low confidence in the solution: **balance**. Build in steps and test each step.
4. Confidence is a scale, not yes or no. Give a number from 0 to 10 for each axis.

## Result file

The two confidence scores with the evidence. The position and the focus (speed, quality, or balance). What data can make each score higher.

## Your view in the chat

For each main solution from other agents, say if it needs speed or quality. Warn when an agent wants to build a perfect solution for a problem that nobody has proven.

## If it does not fit

This tool fits all problems that have a solution. If there is no solution yet, rate the confidence in the problem only.
