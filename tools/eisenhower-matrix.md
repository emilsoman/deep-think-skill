# Eisenhower Matrix

Source: https://untools.co/eisenhower-matrix/
Group: Decision Making
Use it for: sorting the actions that the problem needs by urgency and importance.

## Steps

1. List all the actions, tasks, or work items that come from the problem. Include the actions that people do now.
2. For each item, decide: is it **important** (it moves the main goal)? Is it **urgent** (it has a near deadline or a cost if it waits)?
3. Put each item in one quadrant:
   - Important and urgent: **Do** now.
   - Important, not urgent: **Schedule**. This is where most long-term value is.
   - Urgent, not important: **Delegate** or automate.
   - Not urgent, not important: **Delete**.
4. Look at the result. Is effort going to the wrong quadrant?

## Result file

A table with the four quadrants and their items. Then 3 to 5 lines: what to stop, what to start, what to give to someone else.

## Your view in the chat

Other agents give many ideas. You say which ideas are urgent, which are important, and which to delete. Push back on work that is urgent but not important.

## If it does not fit

If the problem has no actions yet (it is a pure "why?" question), sort the possible next steps of the investigation.
