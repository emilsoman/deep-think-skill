# Inversion

Source: https://untools.co/inversion/
Group: Problem Solving
Use it for: finding what to avoid, by thinking about how to fail.

## Steps

1. Write the goal.
2. Invert it: "How can we make sure that we fail?" or "How can we make the problem worse?"
3. List many ways to fail. Be specific.
4. For each way to fail, check: do we do this now, completely or partly?
5. Invert each item again: the action to avoid it.

## Result file

The goal. The list of ways to fail, with a mark on those that happen now. The list of actions to avoid them, with the most important first.

## Your view in the chat

Other agents look for what to add. You look for what to stop. Use inversion on the best ideas of other agents: how can each idea fail?
