# Issue Trees

Source: https://untools.co/issue-trees/
Group: Problem Solving
Use it for: breaking a big problem into small parts that you can solve.

## Steps

1. Write the main question at the root. Use a problem tree ("Why ...?") or a solution tree ("How can we ...?").
2. Break the question into sub-questions. The sub-questions must be MECE: they do not overlap, and together they cover all of the parent question.
3. Break each sub-question again until each leaf is small enough to test or to do.
4. Mark the leaves with the most probable effect.

## Result file

The tree as a nested list. Say if it is a problem tree or a solution tree. Then the 3 leaves to work on first, and why.

## Your view in the chat

Check that the team covers all branches. Point out branches that no agent looks at. Point out ideas that overlap.

## If it does not fit

This tool fits all problems.
