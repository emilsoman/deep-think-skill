# Cynefin Framework

Source: https://untools.co/cynefin-framework/
Group: Decision Making
Use it for: finding the type of situation, so that you use the correct method.

## Steps

Put the problem (or each part of it) in one domain:

1. **Clear.** Cause and effect are obvious. Method: sense, categorize, respond. Use best practice.
2. **Complicated.** Cause and effect are known, but you need analysis or experts. Method: sense, analyse, respond. Use good practice.
3. **Complex.** Cause and effect are clear only after the fact. Method: probe, sense, respond. Do safe experiments and grow what works.
4. **Chaotic.** No clear cause and effect. Method: act, sense, respond. Make the situation stable first.
5. **Confusion.** You do not know the domain. Break the problem into parts and put each part in a domain.

## Result file

The domain of the problem, and the domain of each main part. The evidence for each domain. The correct method for each part, and the wrong method that people can use by mistake.

## Your view in the chat

Tell the other agents if their method fits the domain. Example: a detailed plan does not work in a complex domain. Experiments are a waste of time in a clear domain.

## If it does not fit

This tool fits all problems.
