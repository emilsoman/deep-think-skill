# Balancing Feedback Loop

Source: https://untools.co/balancing-feedback-loop/
Group: Systems Thinking
Use it for: finding why a system resists change or stays at one level.

## Steps

1. Find the goal or target of the system (it can be hidden).
2. Find the current state.
3. Find the gap between the goal and the current state.
4. Find the corrective action that the system takes to close the gap.
5. Find the delays. Delays cause overshoot and oscillation.
6. Ask: is this loop the reason that the problem does not change? Which loop resists our solutions?

## Result file

Each balancing loop as "goal → gap → action → state → gap". The delays. How each loop can resist the proposed solutions, and how to change the goal of the loop.

## Your view in the chat

Tell the other agents how the system can push back against their solutions. Example: more marketing brings more users, but support load grows, and quality falls.

## If it does not fit

If you find no balancing loop, give the most probable limit that a solution will hit.
