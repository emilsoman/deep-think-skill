# Iceberg Model

Source: https://untools.co/iceberg-model/
Group: Systems Thinking
Use it for: looking below the events to find the structures that cause them.

## Steps

1. **Events.** What happened? What do people see? (Above the water.)
2. **Patterns.** What happens again and again over time? What trends are there?
3. **Structures.** What causes the patterns? Rules, incentives, processes, tools, how people and parts connect.
4. **Mental models.** What beliefs, values, and assumptions keep the structures in place?

Actions on the lower levels have more effect than actions on events.

## Result file

The four levels with their items. Then one action for each level, and which action has the most effect.

## Your view in the chat

Other agents can react to events. You show the structure and the mental model below. Say when a solution only fixes the event and the pattern will come back.

## If it does not fit

If the problem is a single new event with no history, say so. Then give the structures that can make it happen again.
