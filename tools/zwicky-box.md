# Zwicky Box

Source: https://untools.co/zwicky-box/
Group: Problem Solving
Use it for: making many new solutions from combinations.

## Steps

1. Find the parameters (the dimensions) of a solution. Example for a product: user, channel, price model, format.
2. For each parameter, list 3 to 6 possible values. Include unusual values.
3. Make a table: one column for each parameter.
4. Make combinations: select one value from each column. Make some combinations at random, and some on purpose.
5. Keep the 3 to 5 most interesting combinations. Describe each one as a solution.

## Result file

The table of parameters and values. Then the 3 to 5 best combinations, each with one paragraph.

## Your view in the chat

You give the most new options. Use the ideas of other agents as values in your table and make new combinations from them.

## If it does not fit

If the problem is "why?" and not "how?", use the parameters of the possible causes to make combinations of causes.
