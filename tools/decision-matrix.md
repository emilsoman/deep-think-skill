# Decision Matrix

Source: https://untools.co/decision-matrix/
Group: Decision Making
Use it for: comparing many options against many factors with numbers.

## Steps

1. List the options (rows). If the problem gives no options, make 3 to 5 possible solutions.
2. List the factors that are important for the decision (columns).
3. Give each factor a weight from 1 (not important) to 5 (very important).
4. Give each option a score for each factor, from 0 (bad) to 5 (very good).
5. Multiply each score by the weight of its factor. Add the results for each option.
6. The option with the highest total is the first candidate. Check if the result agrees with your intuition. If not, find the factor that is missing.

## Result file

The matrix as a Markdown table with weights and totals. Then the winner, the runner-up, and the factor that decides between them.

## If it does not fit

If there is no decision (a pure "why?" problem), compare the possible causes. Factors: evidence, how easy it is to test, size of the effect.
