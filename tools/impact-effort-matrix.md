# Impact-Effort Matrix

Source: https://untools.co/impact-effort-matrix/
Group: Decision Making
Use it for: finding the actions with the most value for the least work.

## Steps

1. List the possible actions or solutions.
2. For each action, estimate the **impact** (how much it helps with the problem) and the **effort** (time, money, people).
3. Put each action in one quadrant:
   - High impact, low effort: **Quick wins**. Do these first.
   - High impact, high effort: **Major projects**. Plan these.
   - Low impact, low effort: **Fill-ins**. Do these when there is time.
   - Low impact, high effort: **Thankless tasks**. Do not do these.
4. Say how sure you are about each estimate.

## Result file

The four quadrants with their actions. Then the top 3 quick wins and the one major project to plan.

## Your view in the chat

Put the ideas of the other agents in your quadrants. Say which ideas are thankless tasks.

## If it does not fit

If there are no actions yet, rate the possible next steps of the investigation.
