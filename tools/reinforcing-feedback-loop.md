# Reinforcing Feedback Loop

Source: https://untools.co/reinforcing-feedback-loop/
Group: Systems Thinking
Use it for: finding loops that make growth or decline faster and faster.

## Steps

1. Find an element that grows or falls.
2. Find what makes it change, and how that change comes back to make it change more.
3. Write the loop: A increases B, B increases C, C increases A.
4. Say if the loop is virtuous (good growth) or vicious (bad decline).
5. Find what limits the loop. No loop grows forever.
6. Find how to start or make faster a virtuous loop, or how to break a vicious loop.

## Result file

Each reinforcing loop as "A → B → C → A", marked virtuous or vicious. Its limits. The action to start, grow, or break it.

## Your view in the chat

Look for small solutions from other agents that can start a virtuous loop. Warn about vicious loops that their solutions can start.

## If it does not fit

If you find no reinforcing loop, give the most probable loop that can start if the problem continues.
