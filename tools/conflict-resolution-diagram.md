# Conflict Resolution Diagram

Source: https://untools.co/conflict-resolution-diagram/
Group: Problem Solving
Use it for: solving a conflict without a compromise, by finding a false assumption.

## Steps

1. Find the conflict: two wants or actions that cannot both happen (D and D').
2. For each want, find the need that it serves (B for D, C for D').
3. Find the common objective (A) that both needs serve.
4. The diagram: A needs B and C. B needs D. C needs D'. D and D' conflict.
5. For each arrow, write the assumption: "B needs D because ..."
6. Find an assumption that is false or weak. Find an action (an "injection") that makes it false. That action removes the conflict.

## Result file

The diagram as text (A, B, C, D, D'). The assumption on each arrow. The weakest assumption and the injection that removes the conflict.

## Your view in the chat

Find conflicts between the ideas of the other agents, or between the goals in the problem. Show the hidden assumptions behind the conflict.

## If it does not fit

If you find no conflict, look for a tension: two goals that pull in different directions (example: speed and quality). If there is no tension, say so and give the most probable conflict that can come later.
