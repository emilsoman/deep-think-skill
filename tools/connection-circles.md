# Connection Circles

Source: https://untools.co/connection-circles/
Group: Systems Thinking
Use it for: finding the cause-and-effect loops in a system.

## Steps

1. Select 5 to 10 elements of the problem. Each element must be a thing that can increase or decrease (example: "number of users", "support load").
2. Put the elements in a circle.
3. For each pair, ask: does a change in A cause a change in B? If yes, draw an arrow A → B. Mark it **+** (same direction) or **−** (opposite direction).
4. Find the closed loops. A loop with an even number of − arrows is reinforcing. A loop with an odd number of − arrows is balancing.
5. Find the elements with the most arrows. These are the places where a change has the most effect.

## Result file

The elements. The arrows as a list ("A → B (+)"). The loops, each marked reinforcing or balancing. The elements with the most effect.
