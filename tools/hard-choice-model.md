# Hard Choice Model

Source: https://untools.co/hard-choice-model/
Group: Decision Making
Use it for: deciding how much effort a decision needs.

## Steps

1. Find the decision in the problem. List the options.
2. Ask: how much **impact** does the decision have?
3. Ask: how easy is it to **compare** the options?
4. Put the decision in one quadrant:
   - Low impact, easy to compare: **No-brainer**. Decide quickly.
   - Low impact, hard to compare: **Apples and oranges**. Use the current priorities to decide.
   - High impact, easy to compare: **Big choice**. Get enough information and compare with care.
   - High impact, hard to compare: **Hard choice**. Accept that there is no correct answer. Use a decision matrix, small experiments, and your values.
5. Say how to make the decision with the method of its quadrant.

## Result file

The quadrant and why. The method to decide. If it is a hard choice: the values that decide, and a small experiment that can make the options easier to compare.

## Your view in the chat

Tell the other agents how much effort the decision deserves. If the team spends too much effort on a no-brainer, say so. If it is a hard choice, say that more analysis will not give one correct answer.

## If it does not fit

If there is no decision in the problem, apply the tool to the decision about which solution to try first.
